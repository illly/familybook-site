1. 운영자와 문의

familybook은 운영자가 집에서 관리하는 개인용 서비스입니다. 개인정보 및 YouTube API 데이터 처리 문의와 삭제 요청은 운영자 이메일 psiluv@gmail.com로 보내 주세요.

2. 처리하는 정보와 이용 목적

familybook은 가족이 사진과 동영상을 보고 관리할 수 있게 하며, 관리자가 직접 고르거나 게시 규칙으로 지정한 동영상을 YouTube에 게시하는 기능을 제공합니다.

  • 가족 계정: Google 로그인으로 확인되는 이름, 이메일 주소, Google 계정 식별자. 가족 구성원 로그인, 운영자 승인, 접근 권한 관리에 사용합니다.
  • YouTube API 정보: 사용자가 승인한 YouTube 계정의 OAuth 접근·갱신 토큰, 업로드한 동영상의 YouTube ID·주소·게시 시각. YouTube 계정 연결과 동영상 게시 여부 확인에 사용합니다. 서비스는 YouTube Data API의 youtube.upload 권한을 사용합니다.
  • 게시할 미디어와 설명: 관리자가 Immich 보관함에서 고르거나 게시 규칙에 포함한 동영상, 사용자가 작성한 설명, 촬영 날짜·장소·인물 이름 등 설명에 포함되는 메타정보. 동영상 게시 요청 시 동영상과 설명이 YouTube에 전송됩니다. GPS 좌표는 게시 설명에 넣지 않습니다.
  • 서비스 기록: 가족 구성원의 사진 반응·댓글·즐겨찾기와 운영 로그 등 기능에 필요한 기록을 집의 서버에 보관합니다.

3. 저장 위치와 보유 기간

familybook은 공개 클라우드 서비스가 아닙니다. 가족 계정, YouTube OAuth 자격 증명, 게시 이력, 댓글·반응 등 서비스 기록은 운영자의 집의 Mac 서버에 보관됩니다. 원본 사진·동영상과 관련 메타정보는 운영자가 관리하는 Immich 서버에 보관됩니다. 운영자는 서비스 제공에 필요한 기간 동안 정보를 보유합니다. 삭제 요청은 운영자 이메일로 접수할 수 있으며, 요청을 확인한 뒤 해당 계정·토큰·게시 기록을 자체 호스팅 서버에서 삭제합니다. Google 계정 설정에서 familybook의 접근 권한을 철회할 수 있습니다. YouTube에 이미 게시한 동영상은 YouTube에 남을 수 있으므로 YouTube에서도 별도로 삭제해야 합니다.

4. 제3자 서비스 제공

familybook은 다음 기능을 사용자가 선택한 경우에만 외부 서비스와 통신합니다.

  • Google 로그인: 로그인 확인을 위해 Google에 인증 요청을 합니다. Google의 데이터 처리는 Google 개인정보처리방침을 따릅니다.
  • YouTube API Services: 사용자가 승인한 계정으로 동영상을 업로드합니다. 게시한 동영상과 설명은 해당 YouTube 계정의 설정에 따라 YouTube에서 보관·처리됩니다. 기본 공개 범위는 비공개이며, 관리자가 게시 규칙에서 공개 범위를 변경할 수 있습니다.
  • Google Gemini (선택 기능): 글 생성 제공자를 Gemini로 설정하고 글 생성 기능을 사용하는 경우, 해당 사진 미리보기와 촬영 날짜·장소·인물 메타정보가 Google로 전송되어 설명문 생성에 사용됩니다. 기본 제공자는 집의 Mac에서 실행하는 로컬 모델입니다.
  • Threads (선택 기능): Threads 게시 기능을 연결해 사용하는 경우, 선택한 사진과 설명이 Meta/Threads에 전송됩니다.
  • GitHub Pages: 이 안내 사이트를 제공하는 호스팅 사업자입니다. 웹 브라우저의 접속 정보가 호스팅 과정에서 처리될 수 있습니다. 이 사이트는 분석 도구, 광고, 쿠키 또는 입력 양식을 사용하지 않습니다. 자세한 내용은 GitHub 개인정보처리방침을 확인하세요.

5. 보관함 접근과 보안

운영자는 서버와 계정 접근을 관리하고, 로그인 승인을 통해 가족 계정 접근을 제한합니다. YouTube API 자격 증명은 운영자의 자체 호스팅 서버에 보관하며, 광고 목적으로 사용하지 않습니다. 가족 사진과 동영상은 사용자가 선택하거나 게시 규칙으로 지정해 게시하기 전에는 YouTube로 전송되지 않습니다.

6. 동의 철회와 삭제

Google 계정 설정에서 familybook의 접근 권한을 철회할 수 있습니다. 또한 psiluv@gmail.com으로 계정·토큰·서비스 기록의 삭제를 요청할 수 있습니다. 게시된 동영상은 YouTube에서 직접 삭제해야 합니다.

7. YouTube API Services

familybook의 YouTube API Services 사용에는 YouTube 서비스 약관과 YouTube API Services 이용약관 및 YouTube API 개발자 정책이 적용됩니다. Google의 정보 처리에 대해서는 Google 개인정보처리방침을 확인하세요.

8. 방침 변경

처리 방식이 변경되면 이 페이지에 변경 내용과 시행일을 게시합니다.
