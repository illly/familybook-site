familybook은 운영자와 승인된 가족이 사용하는 자체 호스팅 서비스입니다.

YouTube 연동

familybook의 YouTube 기능을 사용하면 YouTube 서비스 약관에 동의하고 이를 준수해야 합니다. YouTube API Services는 YouTube 동영상을 선택한 계정으로 게시하는 데 사용됩니다.

외부 서비스와 게시물

YouTube 또는 Threads에 게시한 콘텐츠는 해당 서비스의 약관 및 공개 범위 설정에 따릅니다. 외부 서비스에 게시된 콘텐츠를 삭제하려면 해당 서비스에서 삭제해야 합니다.
